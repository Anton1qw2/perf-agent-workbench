# Performance investigation knowledge

## Applicability
Reference guidance for function and stack investigations. Child documents describe
more specific areas. Conflicting guidance remains an explicit limitation.

## Evidence requirements
Runtime observations require supplied profiler evidence with its original values,
units and collection scope. Source code and documentation alone do not establish
runtime cost or a performance improvement.

## Investigation approach
Separate observations from explanations. Compare alternative explanations through
available read-only queries. Keep unknown metric semantics and build linkage explicit.
Recommendations describe proposed changes or checks, with a validation plan.

## Limitations
This knowledge tree does not grant tool permissions or authorize code execution.
No optimization result is established by applying this guidance.
